# Manga Reader App

تطبيق قارئ مانجا متميز يجمع بين أفضل ميزات تطبيقات مثل Tachiyomi وغيرها، مع إضافة ميزات فريدة تجعله الخيار الأمثل لعشاق المانجا.

## المميزات

- **دعم متميز للمصادر العربية**: مانجا سوات، مانجا ليونز، تيم إكس، وغيرها
- **نظام مصادر متطور**: إمكانية إضافة مصادر خارجية عبر روابط repositories
- **تقنيات متقدمة لتجاوز الحماية**: تجاوز CloudFlare وCAPTCHA وقيود معدل الطلبات
- **تجربة قراءة متميزة**: دعم اتجاهات القراءة المختلفة، تحسين الصور، القراءة المستمرة
- **نظام تنزيل متطور**: تنزيل الفصول والمانجا للقراءة دون اتصال
- **واجهة مستخدم حديثة واحترافية**: تصميم Material Design، دعم الوضع الداكن
- **خالٍ من الإعلانات**: تجربة استخدام نظيفة بدون إعلانات مزعجة

## الميزات الفريدة

- **مزامنة المكتبة والتقدم في القراءة**: مزامنة بياناتك عبر أجهزة متعددة
- **إشعارات ذكية بالفصول الجديدة**: تلقي إشعارات عندما تتوفر فصول جديدة للمانجا المفضلة لديك
- **تصنيف وتنظيم متقدم للمانجا**: تنظيم مكتبتك باستخدام نظام الفئات المتقدم
- **إحصائيات مفصلة عن عادات القراءة**: عرض إحصائيات مفصلة عن عادات القراءة الخاصة بك

## متطلبات النظام

- Android 5.0 (Lollipop) أو أحدث
- مساحة تخزين: 50 ميجابايت كحد أدنى
- اتصال بالإنترنت للتصفح والتنزيل

## التثبيت

1. قم بتنزيل أحدث إصدار من ملف APK من [صفحة الإصدارات](https://github.com/Nafro-glitch/manga-reader/releases)
2. قم بتمكين "التثبيت من مصادر غير معروفة" في إعدادات جهازك
3. افتح ملف APK وقم بتثبيت التطبيق
4. استمتع بقراءة المانجا المفضلة لديك!
